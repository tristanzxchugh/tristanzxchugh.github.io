matching image is added here with the exact filename below. Drop the file in
and refresh. No HTML or CSS changes needed.

## Supporting web development
| File | Tile |
| --- | --- |
| `html_logo.png` | HTML |
| `css_logo.png` | CSS |
| `java_logo.png` | Java |
| `github_logo.png` | GitHub |

If your existing file is named differently (e.g. `css_light` instead of
`css_logo.png`), either rename it to match the table above or update the
matching `data-logo-src` value in `index.html`. Both work the same way.

Use a square image, ideally 128×128px or larger, transparent or white
background. If a file is missing or fails to load, the two-letter label
stays visible automatically, so nothing breaks while you're still adding
logos.
